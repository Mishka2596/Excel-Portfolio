# Excel-Portfolio

### [Employee KPI Tracker](https://github.com/Mishka2596/Excel-Employee-KPI-Template)

*Focus: Employee Performance Monitoring & KPI Tracking*

- **The Problem:** Managers lacked a structured way to monitor employee KPI progress, performance trends, and accountability across reporting periods.

- **The Solution:** Developed an interactive Excel KPI tracker to monitor employee performance, calculate KPI achievement scores, and improve visibility into performance management processes.

- **Key Tech:** Excel, Pivot Tables, KPI Tracking, Conditional Formatting, Performance Analysis, Data Validation

- ### 🧹 [Data Cleaning Project](https://github.com/Mishka2596/Excel-Retail-Dashboard))

*Focus: Data Cleaning & Data Preparation*

- **The Problem:** Raw datasets contained inconsistent formatting, duplicate records, missing values, and incorrect data structures which reduced reporting accuracy.

- **The Solution:** Performed data cleaning and transformation processes to standardise datasets, improve data quality, and prepare data for reporting and dashboard analysis.

- **Key Tech:** Excel, Data Cleaning, Duplicate Removal, Data Formatting, Data Validation, Lookup Functions
